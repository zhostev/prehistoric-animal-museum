Velociraptor model source and modifications
===========================================

Direct source:
https://archive.org/details/thingiverse-3784576 (Thingiverse 3784576 mirror)

Creator: Greg Criddle (Noximous)
License: CC-BY-4.0
Original downloaded source: 27489484 bytes (archive/Raptor_Standing_Final.stl,
from the 59511624-byte Raptor_Pack_3784576.zip)

Modifications for the Prehistoric Animal Museum:
- Model replaced with the 'Raptor Pack' (Standing pose) sculpt via the
  static-sculpt pipeline track (run_static_sculpt).
- decimate: ratio 0.163699 (549788 -> 90000 tris, 44741 verts)
- scale: source body length 39.4398 Blender units -> 2.0 m; factor 0.050710
  applied to mesh data
- grounding (land): lowest vertex rests at z=0
- skinning: deterministic 20-step Body/Head/Tail blends by local +Y
- Idle synthesized: frames 0..192 at 24 fps = 8.0 s, LINEAR per-frame keys;
  Body breathes, Head sways +/-2.4 deg, Tail sways +/-3.5 deg with a 2.2 rad
  phase lag; frame 192 repeats frame 0 exactly (seamless loop)
- texture bake: deterministic Smart UV unwrap + Cycles diffuse bake (scales
  pattern), 1024px Body (texture_materials.py)
- mouth motion stays DISABLED (static sculpt, no declared jaw path)

This record supersedes the earlier Quaternius CC0 low-poly Velociraptor
(recorded in git history before 2026-08-12).
