# 剑齿虎生态微地台（Diorama）一体化模型测试设计规范

**日期:** 2026-09-18  
**作者:** Antigravity  
**状态:** Approved  
**目标:** 验证“动物+环境生态微地台”一体化模型在史前动物博物馆中的落地效果。以剑齿虎（`smilodon`）为样板，消除 3D 悬浮模型与 2D 背景之间的视觉割裂与浮空感，实现博物馆标本级的空间融合与脚踏质感。

---

## 1. 现状与痛点分析

- **现状架构**：展示端使用 Three.js 渲染独立的动物 3D 模型（GLB），模型下方配置扁平的 2D 接触阴影面片（`contact-shadow`），背景为 2D 画作（landscape/portrait WebP）。
- **核心痛点**：
  1. **接触不真实**：四足动物爪尖与扁平地面缺乏几何咬合，接触阴影仅为平面椭圆/模糊渐变，缺乏足部凹凸闭塞（AO）。
  2. **透视割裂**：摄像机 360 度旋转时，背景图是静态二维透视，纯单体动物在空旷舞台中产生“漂浮标本”或“贴画感”。
- **解决路径**：引入**生态微切片地台（Natural Diorama Plinth）**，将剑齿虎生存的更新世晚期冻土/岩石地貌微缩切片与动物本体整合为一体化 GLB 模型。

---

## 2. 三维地台设计与几何工程规范

### 2.1 地台形态与拓扑
- **自然切片断层 (Organic Geological Slice)**：
  - 避免机械死板的圆盘或方形基座，采用晚更新世北美开阔荒原地貌特征（风化岩层、粗粝冻土、石砾微起伏）；
  - 边缘呈现自然的物理剥离感，底面收平归零（$y=0$ 绝对贴地）。
- **尺寸与比例**：
  - 剑齿虎模型总长约 2.1m，肩高约 1.2m；
  - 微地台主轴长约 2.5m ~ 2.7m，横轴宽约 1.7m ~ 1.9m，平均厚度 0.15m ~ 0.22m；
  - 地台紧凑包裹四足落点，既提供充实的地面承托，又不喧宾夺主。
- **足部嵌合与微凹痕**：
  - 基于剑齿虎 4 个脚掌的世界坐标顶点分布，对微地表对应位置做贴合形变，确保爪掌与岩石、泥土紧密贴合，消除任何间隙或穿插。

### 2.2 材质与烘焙标准
- **PBR 地貌材质**：
  - 基色（BaseColor）：低饱和度的古冻土黄灰、岩石灰褐，与远景草甸氛围协调；
  - 粗糙度（Roughness）：0.85，漫反射为主；
  - 法线贴图（Normal）：细腻的碎石与泥土微表面颗粒感。
- **接触遮蔽（Contact AO）**：
  - 在四爪落脚点及身体下方烘焙物理接触软阴影，即使在无动态光影的纯环境光下依然有立体的接触深度。

## 3. 动画隔离与馆藏性能预算

### 3.1 骨骼动画隔离
- 现有剑齿虎由 2 根骨骼（`Body`、`Head`）驱动 8.0 秒（192 帧 @ 24fps）的待机呼吸与摆头动作（`clip: "Idle"`）。
- 地台网格（`Smilodon_Plinth`）保持静态，不分配骨骼顶点权重（`Weight = 0`）。
- 动画播放时，剑齿虎身体与头部平缓起伏，四爪稳踩地台，地台绝对静止。

### 3.2 性能预算 (Museum Asset Standards)
- **地台面数**：$\le 15,000$ 三角面；
- **合并后总面数**：$\le 60,000$ 三角面（远低于馆藏 100,000 面上限）；
- **GLB 体积**：经 Draco / Meshopt 优化后控制在 $2.5\text{MB}$ 以内（远低于馆藏 12MB 上限）；
- **纹理尺寸**：$1024 \times 1024$ 或 $2048 \times 2048$ WebP/PNG，合规打包于 GLB 内。

## 5. 验证与对比验收标准

1. **几何与动画验证**：
   - 检查 GLB 结构，验证动画仅驱动剑齿虎网格，地台网格无抖动、无变形；
   - 验证四足与地面零穿模、零浮空。
2. **静态预览多角度验证**：
   - 运行 `tsx scripts/render-model-previews.ts --target=production --animal=smilodon`；
   - 检查生成的 6 个角度（正视、侧视、顶视、斜视等）WebP 预览图。
3. **前端渲染与回归测试**：
   - 运行 `npm run check:content`，确保内容与资产完整性全部通过；
   - 运行 `npm run test`，确保全套单测通过；
   - 在真实展示页面（`npm run dev`）中观察 3D 旋转手感与光影表现。
