# 史前动物博物馆：背景契合度与动物模型优化设计方案 (Design Specification)

## 1. 背景与目标 (Context & Objectives)

在当前史前动物博物馆（Prehistoric Animal Museum）中，主目录收录了 50 种古生物的 3D 模型与栖息地背景。随着展品扩充至 50 种，用户反馈了两个核心痛点：
1. **很多背景和动物没有很好的契合**：动物在背景中产生“悬空感/浮空感”，地面阴影与背景透视脱节，3D 模型的环境受光颜色与 2D 背景照片色温割裂，像生硬贴图。
2. **部分动物模型不够完美**：部分 AI 生成的模型存在肢体解剖比例生硬、贴图细节粗糙或骨骼待机动画（Idle）卡顿不自然的问题。

本项目标为：
- 升级 3D 渲染与环境光照管线，实现根据动物生态环境（`atmosphere`）自动适配的环境半球光与差异化阴影；
- 全量校准 50 只动物的 3D 视口对齐参数（垂直沉降、接触阴影、安全边距与展示偏航角），确保陆生动物扎实落地，水生/飞行生物空间层次分明；
- 建立 50 只动物全量质量诊断矩阵，对轻度瑕疵进行参数/视角微调，对重度瑕疵的模型和背景进行靶向替换与合规重构。

## 2. 渲染层增强：生境自适应光影与多模式阴影 (Rendering & Lighting Enhancements)

### 2.1 生境半球光调色板 (Atmospheric Hemisphere Lighting)
目前 `ViewerController.ts` 使用固定半球光：天光 `#fff8df`、地光 `#71805e`（草绿）。水下和冰原动物身上均带有草绿色反光。

我们在 `ViewerController` 中引入根据动物 `atmosphere` 或 `presentation.atmosphereLighting` 动态配置的调色板：

| 氛围类型 (`atmosphere`) | 天空光 (Sky Light) | 地表漫射光 (Ground Light) | 强度 (Intensity) | 视觉效果 |
| :--- | :--- | :--- | :--- | :--- |
| `forest` (森林/丛林) | `#eef5e5` (清晨林冠漫射) | `#5c6e46` (苔藓绿植漫反射) | 1.30 | 还原原生生机盎然的森林光影 |
| `underwater` (深海/浅礁) | `#82c3ec` (海面透光水蓝) | `#1d3557` (深海幽蓝底光) | 1.45 | 消除草绿地光，呈现水下浸润质感 |
| `plains` / `desert` (荒原/红岩) | `#fff4e6` (温暖烈日) | `#a67c52` (沙岩/红土地表漫射) | 1.35 | 荒原与远古戈壁暖阳 |
| `ice` (冰原/极地) | `#f0f8ff` (冷白霜天) | `#b0c4de` (淡冰蓝冻土反光) | 1.25 | 突出冰原刺骨冷冽感 |
| `air` (高空/悬崖) | `#ffffff` (纯白天光) | `#7a8b99` (高空稀薄大气) | 1.30 | 增强高空直射对比度 |

当动物切换时，半球光颜色平滑过渡更新，使 3D 模型表面的受光与环境背景完全同色调。

### 2.2 阴影分级机制 (Adaptive Shadow Modes)
针对三类不同的生物栖息地（`habitat`: `land` / `water` / `air`），提供差异化阴影处理：
1. **陆生动物 (`land`)**：
   - 保持地面接触阴影 (`ground`)；
   - 优化阴影柔和度，根据动物足部实际分布微调 `shadowScale` 与 `shadowYOffset`，确保脚掌底面实贴地面。
2. **水生动物 (`water`)**：
   - 默认将硬质贴地阴影置为关闭（`shadow: 'none'` 或 `shadowOpacity: 0`）；
   - 水生动物自由悬浮于海水背景中，配合水中氛围粒子，彻底打破“趴在海底”的僵硬感。
3. **飞行生物 (`air`)**：
   - 阴影支持大半径、高羽化、低透明度模式（`shadowOpacity: 0.15~0.22`，`shadowScale: 1.3~1.6`）；
   - 营造“在高空振翅，地面投影虚化拉远”的真实空间高度差。

## 3. 地平线与视口落脚点校准规范 (Ground & Viewport Alignment)

### 3.1 陆生动物接地校准 (Ground Contact Alignment)
- 背景图片的地面地平线普遍位于画面中下部（大约 65%~75% Y轴深度处）。
- 在各动物 `package.ts` 的 `presentation` 中，配置精准的 `landscapeVerticalOffset`（通常为 `-0.08` 至 `-0.18`）与 `portraitVerticalOffset`，将 3D 模型落脚点精确下沉至背景实地。
- 联动调整 `shadow.yOffset`，确保阴影与动物脚底完美咬合，杜绝浮空。

### 3.2 展品尺度与展示安全区 (Scale & SafeArea Padding)
- **大型蜥脚类与顶级掠食者**（如阿根廷巨龙、腕龙、霸王龙）：
  - 调整 `safeAreaPadding` 至 `0.14~0.18`，避免头部或长尾顶穿顶部栏或被底栏文字遮挡；
- **小型敏捷生物**（如美颌龙、小盗龙）：
  - 适当收紧 `safeAreaPadding`（如 `0.08~0.10`），适度拉近镜头展现羽毛与利爪细节。

### 3.3 黄金展示偏航角 (Initial Yaw Tuning)
- 杜绝死板的正前脸或绝对 90 度侧面；
- 统一校准 `initialYawDegrees` 为 **3/4 侧身微倾角**（推荐 `-60°` 至 `-80°` 或 `60°` 至 `80°`），让观众第一时间看清头部表情、躯干骨骼与尾部动态。

## 4. 50 只动物诊断分级与资产治理 (Catalog Audit & Asset Triage)

对主目录全量 50 只动物进行三级质量划分：

### 4.1 诊断标准
- **A 级 (优良基底)**：模型网格自然、解剖结构严谨、骨骼待机动画自然、背景为真实古地理地貌。仅需接入自适应光照与视口微调。
- **B 级 (轻度瑕疵)**：模型可用但默认视角呆滞、待机动画过快/过慢或背景地平线偏高。通过调整 `package.ts` 参数（`speed`、`initialYawDegrees`、`landscapeVerticalOffset`）或重裁背景图解决。
- **C 级 (严重瑕疵)**：
  - 模型存在严重 AI 伪影（如肢体粘连、脚趾缺失、头部比例崩坏、泥塑感网格）；
  - 背景图片存在现代人类人造物或与该物种生存纪元完全相悖的现代生物。
  - **处理手段**：优先更换高质量标准资产，严守交付门槛。

### 4.2 资产替换门槛与合规 (Delivery Gates)
遵循 `ANIMAL_AUTHORING_GUIDE.md`：
1. **3D 模型**：
   - 格式必须为自包含 glTF 2.0 (`.glb`)；
   - 体积目标 ≤ 12MB（硬上限 20MB）；
   - 三角面 ≤ 100,000 面（硬上限 250,000 面）；
   - 仅包含单一 `Idle` 循环动画；
   - 必须通过 `tools/model-pipeline` 的规范化与校验流程。
2. **背景图像**：
   - 必须为古环境地质风貌（无现代电线杆、人行道或人造物）；
   - 分辨率标准化：横屏 `1920x1080`，竖屏 `1080x1920` WebP；
   - 自动更新 `provenance.ts` 与 SHA-256 校验和。

## 5. 实施与验证流程 (Implementation & Verification)

1. **渲染器改造**：在 `src/viewer/ViewerController.ts` 实现生境光照与阴影模式支持，并在 `create-viewer-model-descriptor.ts` 中完成类型对接；
2. **单元测试与类型验证**：更新 `tests/` 和 `vitest`，验证不同 atmosphere 的光照参数与 fallback；
3. **全量参数校准**：逐一审查并更新 `src/content/animals/*/package.ts` 中的视口与光影参数；
4. **靶向资产修复**：对排查出的 C 级模型和背景执行替换与哈希更新；
5. **完整构建与回归**：
   - 运行 `npm run test`（Vitest 单元测试）；
   - 运行 `npm run lint`；
   - 运行 `npm run check:content`（内容合法性与哈希一致性检查）；
   - 启动本地开发服务，人工抽检各分类典型展品的视觉契合效果。
